# 记忆

[English](memory.md) | 中文

DeepSeekGUI 把记忆保存在两份普通 Markdown 文件里。全局记忆记录跨项目偏好，由你编辑；项目记忆记录单个项目的事实，可以由助手维护，也可以在应用内编辑。

## 全局记忆

全局记忆保存在当前 Harness Home 的 `memory.md`，供使用该 Home 的项目读取。

- 在**设置 → 全局记忆**中编辑。助手读取这份文件，内容由你决定。
- 适合保存语言、代码规范、审查要求等长期偏好。
- 保存时会检查当前 Home 和原文。如果其他窗口或编辑器已经改过文件，请重新加载后再保存。

## 项目记忆

项目记忆以 `<文件夹名>.memory.md` 的形式保存在工作区里。

- 助手可以用普通文件工具维护它，记录项目背景和已确认的决定。
- 打开会话中的**记忆**视图阅读或编辑。编辑期间如果文件被别处修改，保存会拒绝覆盖。
- 文件变得难读时，可以使用**让助手整理**。
- 阅读面板最多展示前 20,000 个字符，并提示截断。这个显示限制不影响磁盘上的文件容量。

## 从增强记忆升级

DeepSeekGUI 1.2.0 移除实验性的增强记忆及条目模式入口，回到原版 Markdown 记忆流程。

首次启动时，仍有效的普通条目会追加进全局或项目记忆，仅跳过完整原文相同的内容，已有 Markdown 内容保留。已遗忘条目、接续记录、无法读取的记录，以及项目文件夹已不存在的条目留在旧备份里，避免自动注入。

旧存储保留在 `<Harness Home>/storages/deepseekgui_memory`，`MIGRATED-TO-MARKDOWN.txt` 记录转换结果。升级后请检查两份 Markdown；需要找回未转换的材料时，可查看保留的备份。

## 规则与会话上下文

全新 Managed Home 会在全局 `AGENTS.md` 缺失时创建它；已有规则保留。

Harness 在每个新会话开头按上下文预算带入两份记忆文件。编辑用于新会话；已发送到现有会话里的内容保持原样。

卸载时即使选择**删除数据**，也保留全局 `memory.md` 和 `AGENTS.md`。项目记忆仍在工作区里；其他应用数据按卸载选择处理。

记忆是模型上下文的一部分。公开项目或随报告分享之前，请先检查项目记忆。
