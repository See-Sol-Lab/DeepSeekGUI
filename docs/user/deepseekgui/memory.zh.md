# 记忆

[English](memory.md) | 中文

DeepSeekGUI 把记忆保存在两份普通 Markdown 文件里。全局记忆记录跨项目偏好，由你编辑；项目记忆记录单个项目的事实，可以由助手维护，也可以在应用内编辑。

## 全局记忆

全局记忆保存在当前 Harness Home 的 `memory.md`，供使用该 Home 的项目读取。

- 在**设置 → 全局记忆**中编辑。助手读取这份文件，内容由你决定。
- 适合保存语言、代码规范、审查要求等长期偏好。
- 保存时会检查当前 Home 和原文。如果其他窗口或编辑器已经改过文件，请重新加载后再保存。

## 项目记忆

项目记忆以 `<文件夹名>.memory.md` 的形式保存在工作区里。

- 助手可以用普通文件工具维护它，记录项目背景和已确认的决定。
- 打开会话中的**记忆**视图阅读或编辑。编辑期间如果文件被别处修改，保存会拒绝覆盖。
- 文件变得难读时，可以使用**让助手整理**。
- 阅读面板最多展示前 20,000 个字符，并提示截断。这个显示限制不影响磁盘上的文件容量。

## 从增强记忆升级

DeepSeekGUI 1.2.0 移除实验性的增强记忆及条目模式入口，回到原版 Markdown 记忆流程。

首次启动时，仍有效的普通条目会追加进全局或项目记忆，仅跳过完整原文相同的内容，已有 Markdown 内容保留。已遗忘条目、接续记录、无法读取的记录，以及项目文件夹已不存在的条目留在旧备份里，避免自动注入。

旧存储保留在 `<Harness Home>/storages/deepseekgui_memory`，`MIGRATED-TO-MARKDOWN.txt` 记录转换结果。升级后请检查两份 Markdown；需要找回未转换的材料时，可查看保留的备份。

## 新会话什么时候读入记忆

| 情形 | 读什么、什么时候读 |
| --- | --- |
| 新建会话 | 第一次真正发出请求时，读当前 Home 的 `memory.md` 和这个会话工作区的 `<文件夹名>.memory.md`，之后这个会话一直用这一份。还没发第一条时不读。 |
| 会话进行中改了文件 | 已经开始的会话不变；新会话读新内容。 |
| 应用重启后继续旧会话 | 重新加载时读一次当时的文件，此后照旧不变。已经发出去的历史不会被改写。 |
| 分叉会话 | 分叉出的会话是新会话，第一次发出请求时按它自己的工作区读。 |
| 切换 Home 或 Profile | Harness 重启，之后的会话读新 Home 的全局记忆。 |
| 只是切换窗口看另一个会话 | 不读，也不重复带入。 |

每份文件最多读入 64 KB（UTF-8 字节）。这是读取上限，不是模型的 token 预算；中文按 3 字节一个字，约两万多字。超出时只带入前面一部分，并在带入的内容里写明已截断；项目记忆超出时，缩短的是你写的部分，末尾的「归档整理（自动）」区整段带入。全局记忆排在项目记忆前面，两者都排在助手的产品说明和你的 AGENTS.md 规则之后。

在会话的**记忆**视图里可以看到**这个会话开始时带入的记忆**：每份文件是已带入、不存在、空、截断还是读不出来，带入了多少字和字节。会话每加载一次记一条，最近一条是当前这次。这是当时的记录，不是今天的文件。

## 归档时整理项目记忆

归档一个会话时，DeepSeekGUI 会把这段对话里值得延续的内容整理成几条，写进项目记忆，让同一个项目的新会话少重复背景。

- **怎么整理。** 归档照常立刻完成。之后在后台把这段对话已经结束的轮次（只有你说的话和助手的正文，不含工具输出和思考过程）交给当前模型，单独问一次，模型只能回文字，拿不到任何工具，也不会继续对话里的任务。会话本身一个字不加。这会调用一次模型服务，可能产生费用。第一次使用前要在**记忆**视图里看过说明、点**知道了**，在那之前归档不会自动调用模型。
- **什么会被整理。** 累计至少 20 轮你说的话，或至少 30,000 个字的会话，归档时自动整理；更短的会跳过，可以在**记忆**视图里点**整理这段会话到项目记忆**手动整理。模型认为没有值得记的，就什么都不写。同一段会话反复归档不会重复整理；取消归档后又聊了新的，再归档时只整理新增的部分。
- **写在哪。** 写进项目记忆末尾一块带标记的「归档整理（自动）」区，每次最多 8 条、约 1,500 字，模型没确认的标「待核实」。这块区外你写的内容一个字不碰；和文件里已有内容完全相同的条目跳过，只差大小写、标点或数字的不算重复。对话明确推翻了区里某条旧决定时，那一条会划掉并标「已被后来的决定取代」。区满了（约 6,000 字）就不再写，记忆视图会请你整理。写入前会读最新的文件，读完到写之间文件被改了就放弃这次写入，不覆盖。
- **全局记忆只出建议。** 适合所有项目的偏好会列在**设置 → 全局记忆**，点**加入**才写进 `memory.md`，点**忽略**就丢掉。
- **不自动写入的情形。** 只能聊天的目录（用户主目录、盘符根）、系统或应用目录、DeepSeekGUI 自己的代码、以管理员身份运行时，以及记忆文件是链接或目录不可写。这些情况下条目会列在记忆视图里，由你决定要不要加。项目文件夹已删除、找不到这个会话用过的模型、或者归档后马上删掉了会话时，不整理。
- **没整理成。** 模型回答不合格式、被取消、应用中途退出，都不会推进进度，可以在记忆视图里再整理一次；已经写进去的不会重复。
- **开关。** 在**记忆**视图里可以关掉「归档时自动整理」。
- 整理记录保存在 `<Harness Home>/deepseekgui/archive-memory/`，全局建议在 `<Harness Home>/deepseekgui/memory-suggestions.json`。

## 规则与会话上下文

全新 Managed Home 会在全局 `AGENTS.md` 缺失时创建它；已有规则保留。

Harness 在每个新会话开头按上下文预算带入两份记忆文件。编辑用于新会话；已发送到现有会话里的内容保持原样。

卸载时即使选择**删除数据**，也保留全局 `memory.md` 和 `AGENTS.md`。项目记忆仍在工作区里；其他应用数据按卸载选择处理。

记忆是模型上下文的一部分。公开项目或随报告分享之前，请先检查项目记忆。
