# 项目协作指引

## 基本要求
- 根据用户当前任务和项目实际内容开展工作。
- 修改前了解相关文件，保留用户已有成果，将改动控制在任务需要的范围内。
- 尊重用户明确确认的内容、格式和修改范围。
- 完成后简要说明修改内容与验证结果。

## 代码任务
以下要求适用于代码开发与维护：
- 遵循项目已有的技术栈、目录结构和代码风格。
- 优先采用简单、清晰、满足当前需求的实现。
- 使用项目已有的运行和测试方式，进行与改动相称的验证。
- 保留用户尚未提交的改动，不将凭据或敏感信息写入代码。

## 预设适用性
- 本文件是通用初始预设，不代表已经确认的项目事实。
- 当实际工作是其他非代码内容，或预设与当前任务明显不符时，助手需要主动提醒用户修改本项目的 AGENTS.md，以符合用户的实际工作需求。
- 同一处不匹配提醒一次即可；能够按用户要求继续的工作应正常进行。
- 用户未授权修改本文件时，保留原文。
