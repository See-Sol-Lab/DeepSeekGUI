# Agent Note：会话删除等待拥有者结束工作，并保留最小记录

Status: implemented

[English](2026-09-11-desktop-session-deletion.md) | 中文

## 问题

Agent 仍活跃时删除日志，后续写入可能重新生成正文。仅移除列表条目还会留下衍生的搜索内容。

## 决策

桌面为指定 Harness Home 和会话 ID 签署删除请求。临时私钥保留在桌面进程，Harness 只接收公钥。SessionController 和 JSONL 后端都要求组合中的授权策略允许删除。控制器拒绝新的用户输入，等待当前 Agent 活动结束，再释放自己持有的 AgentHandle。独立拥有的子智能体会被明确拒绝，不会因此停止其他会话。

JSONL 在清理正文之前写入删除意图。记录只包含 ID、标题、删除时间、用于权限检查的工作区目录，以及未完成或已完成状态。投影检查点和 SQLite 搜索文档由各自服务清理。会话日志的各代文件和本地附件引用会被删除，目录链接只解除链接。共享的内容寻址附件文件保留，无人引用附件的清理另做。持有删除租约时，POSIX 租约文件的 inode 留在原位。

未完成的删除保留可重试入口。已删除 ID 不能经 JSONL 重新创建、打开或写入。精确会话查询先检查工作区访问权限，再返回已删除或清理未完成。没有额外筛选的标题或 ID 搜索可以返回删除元数据，已清除的消息正文不参与搜索。已经交给调用方的观察快照不能被追溯撤回，但可复用缓存会被清掉，新查询会检查删除记录。

## 原因

Agent 仍然活跃时删除日志，后续写入可能重新生成内容。仅广播移除事件只改变界面，不能释放写入者。通过 Agent 拥有者可以准确等待并释放一个对话，重启整个 Harness 则会中断无关任务。最小记录能够区分已知删除与搜索未命中，同时避免保留第二份正文。

## 影响

本实现已有源码审查和不输出产物的类型检查证据。运行时测试、会话快照、生成的 Remote 产物及安装包验收属于后续验证。本轮 review 没有运行测试或构建安装包。

## 考虑过的替代方案

重启整个 Harness 会打断其他会话；为搜索保留隐藏正文则会保留用户要求删除的内容。本实现释放拥有的 Agent，仅保留元数据。
